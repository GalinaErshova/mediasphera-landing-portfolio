# MediaSphera — версия для портфолио

Этот репозиторий — отдельный форк [`aigalaersh/mediasphera-landing`](https://github.com/aigalaersh/mediasphera-landing). Правки публичного представления ведутся в ветке `codex/portfolio-presentation`; исходный репозиторий не меняется.

Страница статическая: `index.html` и `images/example-walkthrough.svg`. В портфолио она размещается по пути `projects/recommendations/` и публикуется на [galaershova.ru/projects/recommendations/](https://galaershova.ru/projects/recommendations/).

## Изменения портфельной версии

- На странице «Обзор» убраны блоки с числами, примером одной пары и ограничениями системы.
- Удалён бейдж о состоянии пилота; формулировка о размещении модели заменена на «Используется локальная модель».
- Вычитаны оставшиеся тексты по правилам `ru-text` без изменения результатов расчёта.
- На мобильной ширине содержимое секций не расширяет страницу.
